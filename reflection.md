# Reflection – Finance Flow App

## What went well?

Converting my Python script into a Streamlit web app went well. The core logic (income, expenses, and debt) worked correctly, and the app calculates the remaining balance without errors. The interface is simple and easy to use, and I was able to deploy it and share a working link.

## What could I have done better?

I could improve the UI/UX and make the layout clearer (for example, better labels and a more descriptive button like “Calculate Balance”). I also could add input validation and prevent empty or unrealistic values. In addition, I should organize the code more (separating logic and UI more clearly).

## What could I have done better (iteration/steering)?

During the process, I refined small parts of the app. For example, I corrected the balance calculation after noticing an error in earlier testing, and I improved the messages shown to the user (warning, info, success). I could have done more iterations, like adding validation for negative inputs and improving the layout using Streamlit components (columns or sections).

## What could the instructor have done better?

The instructions were clear overall. It could help to include one short example of a high-quality reflection so students understand the expected level of detail.

## What have we learned?

I learned how to transform a Python script into a web app using Streamlit and how the app re-runs when users interact with it. I also learned how to use AI tools as a helper, but still verify logic and calculations myself. This process showed me the importance of testing, debugging, and improving the app step by step.

## How this workflow compares to manual coding

Using an AI agent made the process faster for building the interface, but it still required me to understand the code and fix issues. Compared to manual coding, this workflow is more iterative: build a small part, test it, fix it, and improve it. I learned that I must guide the agent clearly and verify the results.
