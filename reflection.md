# Reflection

In this project, I created a simple finance app using Python and Streamlit.

The app allows users to enter their monthly income, expenses, and debts. Then, it calculates the remaining balance.

I learned how to use functions, inputs, and basic calculations. I also learned how to run a Streamlit app and upload my project to GitHub.

One challenge I had was setting up GitHub and understanding how to upload files correctly. After some practice, I was able to complete the project.

Overall, this project helped me understand how to build a simple app and improve my coding skills.
